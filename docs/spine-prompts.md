# Spine prompts

Paste a prompt into ChatGPT (or any image generator) **with that game's cover attached** (open the cover URL, save it, drag it in).
Save the result as `spines-custom/<bggId>.png`, then run:

```bash
node scripts/make-spines.mjs <bggId>
```

## Template

> Using the attached board game box cover as the only reference, create the SIDE PANEL (spine) of this same box, as a flat, straight-on image, tall and narrow, about 1:5 (e.g. 200×1000 px). Match the cover's real colors, fonts, logo style and artwork. Put the game title "{TITLE}" running top-to-bottom (rotated 90° clockwise), large and fully legible, using the same logo lettering as the cover. Add a small slice of the cover artwork or pattern above/below the title, and the publisher logo near the bottom if one is visible on the cover. No 3D perspective, no shadows, no background, no mockup, nothing outside the spine. Spell the title exactly: "{TITLE}".
